Send an outreach email for a SimplifyOps lead. The user will specify which lead (by company name).

1. **Read the outreach file** from `outreach/[company-name].md` to get the email draft, subject, and contact email.

2. **Confirm with the user** — show them the email one more time before sending. Ask: "Ready to send this to [contact email]?"

3. **Send via Gmail** using the Gmail tools:
   - Send from admin@simplifyops.dev
   - Use the subject line and body from the outreach file
   - Include the prototype link and booking link in the email

4. **Update the lead file** — set status to "Outreach Sent" and record the send date.

5. **Update Notion** — update the lead record status to "Outreach Sent" with today's date.

6. **Update the outreach file** — record the send date.

7. **Report** — confirm the email was sent and when the follow-up should go out (3-5 days).

Always confirm before sending. Never send without user approval.
